# Git و GitHub من الصفر

أكاديمية تفاعلية بالعربي (عامية مصرية) لتعلم Git و GitHub من الصفر تماماً، جزء من منصة أكاديميات Infinity University Activity.

**الموقع المباشر:** https://capwv.github.io/git-from-zero/

## المحتوى

- **15 درس متدرج** (14 درس + مشروع ختامي): من "ليه Git أصلاً؟" لحد نشر أول موقع على GitHub Pages
- **42 سؤال تفاعلي** بتصحيح فوري وشرح لكل إجابة
- **30 تمرين عملي** بمحاولات وكشف حل نموذجي
- **معمل Git تفاعلي** داخل المتصفح: ترمنال محاكي بـ 29 أمر git حقيقي (init, add, commit, log, branch, merge, conflicts, remote, push, pull, clone, reset, revert, restore...) مع 11 مهمة موجهة بتتصحح تلقائياً، ولوحة حالة بتوضح الـ commits والـ branches لحظة بلحظة
- تتبع تقدم محلي (localStorage) لكل درس وسؤال وتمرين

## الدروس

1. ليه Git أصلاً؟ Version Control من الصفر
2. تثبيت Git وإعداده
3. أول repo: init و add و commit
4. قراءة التاريخ: log و show و diff
5. الـ Branches
6. الدمج (Merging)
7. حل الـ Merge Conflicts
8. GitHub والـ Remotes و Clone
9. push و pull
10. GitHub Flow و Issues
11. Pull Requests
12. الـ README و Markdown
13. .gitignore
14. التراجع عن الأغلاط: restore و reset و revert
15. المشروع الختامي: انشر أول موقع على GitHub Pages

## التقنية

صفحة واحدة (index.html) بدون أي build: HTML + CSS + JavaScript خام، محاكي Git مكتوب بالكامل بـ JavaScript (lab-core.js + lab.js)، خلفية متحركة مشتركة (sams-bg.js)، وتصميم داكن متجاوب مع الموبايل.

## التشغيل محلياً

افتح `index.html` مباشرة في المتصفح، أو:

```bash
python -m http.server 8000
```
